# Kotwica Spokoju ⚓

Aplikacja do wyciszenia i uziemienia: oddychanie, technika 5-4-3-2-1, skan ciała, dziennik, afirmacje, szybkie resety i tracker postępów.

Działa w całości w przeglądarce — jeden plik `index.html`, bez instalacji. Notatki zapisują się lokalnie w Twojej przeglądarce.

## Uruchomienie
Otwórz `index.html` albo włącz GitHub Pages: **Settings → Pages → Branch: main / (root)**.
